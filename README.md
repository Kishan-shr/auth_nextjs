# Auth Next.js 🔐

A modern authentication system built with **Next.js**, providing secure login, registration, and session management.

---

## 🚀 Features

* 🔑 User Authentication (Sign up / Login / Logout)
* 🔒 Secure Password Hashing with **bcrypt**
* 🛡️ JWT-based Authentication & Session Management
* 📧 Email Validation
* 🌐 API Routes with Next.js
* 🎨 Styled with modern UI (Tailwind CSS / Custom Styling)
* 📱 Responsive Design

## ⚡ Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/Kishan-shr/auth_nextjs.git
cd auth_nextjs
```

### 2️⃣ Install dependencies

```bash
npm install
# or
yarn install
```

### 3️⃣ Setup Environment Variables

Create a `.env.local` file in the root and add:

```env
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret_key
```

### 4️⃣ Run the development server

```bash
npm run dev
# or
yarn dev
```

Now, open [http://localhost:3000](http://localhost:3000) 🚀
